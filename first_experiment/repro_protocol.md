# Протокол воспроизведения — все эксперименты 2026-08-10 (для ревью)

Цель документа: дать рецензенту точные шаги/команды/критерии приёмки для независимой проверки
каждого результата, описанного в `acceptance_criteria.md` и `findings_and_recommendations.md`,
плюс более позднего эксперимента с throw-блокировкой. Это не пересказ выводов — те уже есть в
двух документах выше, здесь только "как повторить самому".

## Как читать этот документ — важная оговорка про полноту

Не все исходные прогоны воспроизводимы побайтово:

- **Литеральные (можно скопировать как есть)**: промпты для A, B, E, G, старой D — они
  зафиксированы дословно в блок-цитатах `acceptance_criteria.md`.
- **Реконструированные (best-effort, НЕ дословный оригинал)**: промпт для D' (RNFR/RNTO) нигде
  в репозитории не сохранён дословно — ни в `acceptance_criteria.md` (там только пересказ:
  "фича RNFR/RNTO... требующая написания нового кода"), ни в логах (`--print-logs` пишет ответ
  модели, а не исходный промпт), ни в `*_session.json` (эти экспортированные JSON битые —
  сессия обрывалась при экспорте, см. `findings_and_recommendations.md` про "malformed JSON").
  Ниже дана формулировка, реконструированная по описанию фичи + по плану, который сама модель
  составила в ответ на неё (`baseline/Dp_stageB_run1.log`) — использовать как рабочую замену,
  не как исторически точную цитату.
- **Промежуточные состояния промпта/конфига по стадиям (A/B/C) не сохранены отдельно** — все
  правки `agent_prompt.txt`/`opencode.jsonc` вносились прямо в рабочее дерево без коммитов
  между стадиями, поэтому в git есть только кумулятивный финальный диф. Ниже для каждой стадии
  указано, какие именно строки текущего дифа ей соответствовали — при желании изолированно
  повторить конкретную стадию нужно вручную закомментировать/убрать более поздние правки
  (см. пометки "Чтобы изолировать эту стадию" в разделах Stage A/B/C).
- **F (self-consistency, п.5) не прогонялась вообще** в этой сессии — задача только определена
