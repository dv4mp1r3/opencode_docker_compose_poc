Я успешно добавил флаг `--name` в программу на Go. Вот что было изменено:

1. Добавлен импорт пакетов `flag` и `fmt`
2. В функции `main()` добавлен аргумент `--name` со значением по умолчанию "world"
3. Добавлен вызов `flag.Parse()` для обработки аргументов командной строки
4. Использовано значение `*name` вместо захардкоженного "world" в строке вывода

Код теперь позволяет использовать флаг `--name` для изменения приветствия. Например:
- `go run script.go` - выводит "Hello, world!"
- `go run script.go --name="Alice"` - выводит "Hello, Alice!"
