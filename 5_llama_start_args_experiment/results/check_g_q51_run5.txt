Я успешно реализовал флаг --name для Go-программы:

1. Добавил импорт пакета "flag" для работы с флагами
2. Создал строковый флаг --name с значением по умолчанию "world"
3. Добавил вызов flag.Parse() для разбора флагов
4. Изменил вывод приветствия на использование значения флага

Теперь программа:
- При запуске без флага выводит "Hello, world!"
- При запуске с флагом --name выводит "Hello, {value}!" где {value} - значение флага

Python-скрипт уже имел необходимую функциональность, поэтому изменения не требовались.
