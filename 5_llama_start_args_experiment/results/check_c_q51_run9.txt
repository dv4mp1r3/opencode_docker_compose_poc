Добавлен флаг --name для настройки имени в приветствии. Теперь скрипт принимает опциональный параметр --name, который заменяет "world" в приветствии. По умолчанию имя остаётся "world", если флаг не указан.

Для проверки работы скрипта:

1. Скомпилируем и запустим:
   - `go build script.go`
   - `./script.go` (выведет "Hello, world!")
   - `./script.go --name Alice` (выведет "Hello, Alice!")

Скрипт теперь работает с пользовательским именем.
