Я добавил флаг `--name` в программу приветствия. Теперь она использует argparse для обработки аргументов командной строки, где по умолчанию значение `--name` равно "world", но пользователь может передать другое значение для замены на "world" в сообщении приветствия.

Для проверки работы программы я запустил её с разными значениями аргументов:

1. Без указания флага `--name` (используется значение по умолчанию):
   ```
   python greeting.py
   Hello, world!
   ```

2. С указанием имени "Alice":
   ```
   python greeting.py --name Alice
   Hello, Alice!
   ```

3. С указанием имени "Bob":
   ```
   python greeting.py --name Bob
   Hello, Bob!
   ```

Программа корректно обрабатывает аргументы командной строки и выводит приветствие с указанным именем или значением по умолчанию.
